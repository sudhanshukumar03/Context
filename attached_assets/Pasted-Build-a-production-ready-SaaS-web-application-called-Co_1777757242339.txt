Build a production-ready SaaS web application called “Context” — a real-time Company Intelligence Engine focused on incident intelligence for engineering teams.

🎯 CORE GOAL

Create a system that:

Understands relationships between services, teams, tasks, and deployments
Explains why incidents happen (causality, not just data)
Predicts potential failures before they occur
Provides clear, explainable, and actionable insights
❗ IMPORTANT CONSTRAINTS
Write clean, modular, production-level code
Use TypeScript everywhere (frontend)
Follow scalable folder structure
Do NOT build a demo — build a real SaaS foundation
Avoid overengineering UI — focus on clarity + intelligence

semantic similarity
