Build a production-ready SaaS web application called “Context” — an AI-powered Incident Intelligence System that not only shows system health, but explains, predicts, and resolves incidents in real time.

🎯 CORE GOAL

Transform raw system signals (logs, metrics, dependencies) into:

A single clear root cause
A live understanding of cascading failures
Predictions of what will break next
AI-assisted resolution actions

This is NOT monitoring.

This is a real-time decision-making system for engineers.
