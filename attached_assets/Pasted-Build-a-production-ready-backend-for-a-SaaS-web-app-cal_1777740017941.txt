Build a **production-ready backend** for a SaaS web app called **"Context"** — an AI-powered onboarding intelligence system that transforms company knowledge into structured, actionable "Context Briefs".

---

## 🧠 PRODUCT IDEA

Context helps new employees understand company knowledge instantly by:

* Ingesting documents, teams, and tasks
* Structuring relationships between them
* Generating AI-powered onboarding briefs
* Continuously updating insights

---

## ⚙️ TECH STACK (STRICT)

Use exactly:

* Node.js (TypeScript)
* Fastify (preferred) or Express
* PostgreSQL
* Prisma ORM
* Redis (for caching + queue)
* BullMQ (background jobs)
* OpenAI API (or compatible LLM)
* JWT (access + refresh tokens)
* Zod (validation)
* Pino (logging)
* Multer (file uploads)

---

Examples:

* Team → Document
* Document → Task

Store relationships in Relation table.

---

## 🤖 AI CONTEXT BRIEF (ASYNC SYSTEM)

Endpoint:

POST /api/v1/generate-brief

Flow:

1. Add job to BullMQ queue
2. Return jobId immediately
3. Worker processes job:

   * Fetch relevant data
   * Perform embedding similarity search
   * Call OpenAI API
   * Generate structured brief
   * Save in database

---
