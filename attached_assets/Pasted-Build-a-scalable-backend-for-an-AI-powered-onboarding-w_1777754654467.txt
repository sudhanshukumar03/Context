Auth system — POST /api/auth/register and /login with bcrypt (12 rounds), JWT issuance, role-based middleware via authenticate + authorize(...roles). Deactivated accounts are blocked at middleware level.
Document ingestion pipeline — Upload via Multer → extract text (pdf-parse / mammoth / fs) → chunk with sentence-boundary splitting (1000 chars, 200 overlap) → embed with text-embedding-3-small → batch-upsert to Pinecone. Runs async in background so uploads return instantly; status tracked as pending → processing → completed → failed.
AI context engine — On brief request, the system builds a rich query from the user's role + department, retrieves top-8 relevant chunks from Pinecone (filtered to assigned docs), constructs a structured 7-section prompt, and calls GPT-4 Turbo. Briefs are stored in MongoDB and cached in Redis for 1 hour.
Real-time chat — Socket.io with JWT handshake auth. The ask_question event triggers RAG-powered streaming via OpenAI's stream API, emitting answer_chunk tokens progressively and answer_done on completion.
Analytics — Every meaningful user action (brief_generated, question_asked, step_completed, etc.) is fire-and-forget tracked. Admin gets a company-wide dashboard with department progress breakdowns via MongoDB aggregation.
Smart suggestions — GET /api/user/suggestions asks GPT-4 to recommend the 3 most relevant unassigned documents based on role + completed steps, returning titles + reasons + doc IDs.
