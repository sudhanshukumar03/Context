Create a modern, minimal, and visually elegant web app UI called "Context" — an AI-powered onboarding intelligence system.

-----------------------------------

🎯 GOAL:
Design a clean, calm, and highly professional interface that feels intelligent and trustworthy.

This should NOT feel like a flashy demo.
It should feel like a real SaaS product judges would invest in.

-----------------------------------

🧠 CORE IDEA:
The app transforms scattered company knowledge into a personalized "Context Brief" — instantly actionable understanding.

-----------------------------------

🔥 HERO SECTION (VISUAL STORY — VERY IMPORTANT):

Create a split-screen transformation UI:

LEFT SIDE (Chaos):
- Messy UI: scattered docs, Slack messages, confusion
- Slight blur/noise effect
- Text:
  "Weeks to understand anything"
  "Too many tools. No clarity."

RIGHT SIDE (Clarity):
- Clean structured dashboard
- Clear cards, hierarchy
- Text:
  "Clarity in minutes"
  "Know exactly what to do"

CENTER TRANSITION:
- Smooth animated divider (before → after feel)

-----------------------------------

📝 HERO TEXT:

Headline:
"From Zero Context to Clear Action — Instantly"

Subtext:
"AI that understands your company and tells you exactly what matters."

CTA Button:
"See How It Works"

Secondary CTA (small):
"View Demo"

-----------------------------------

⚡ DEMO FLOW (AUTO EXPERIENCE — NO CHATBOT):

On CTA click, animate this sequence:

1. State 1:
   "Uploading company knowledge..."
   (simple loading bar or dots)

2. State 2:
   "Understanding relationships..."
   (subtle network animation)

3. State 3 (KEY MOMENT):
   Show output card:

   📄 Context Brief

   - Team: Payments
   - Goal: Reduce API latency
   - Key Person: Sarah (Tech Lead)
   - Suggested Reading: API Architecture Guide
   - Next Action: Review latency logs

👉 This transition should feel smooth and satisfying.

-----------------------------------

🧩 MAIN DASHBOARD:

Layout: Clean grid (Notion / Linear style)

-----------------------------------

1. 🧠 CONTEXT BRIEF (PRIMARY CARD)
- Highlight box
- Sections:
  - Key Insight
  - Next Action
  - Who to Talk To
- Add:
  "Why this matters"

-----------------------------------

2. 🕸️ CONTEXT GRAPH (INTERACTIVE)
- Nodes:
  - You
  - Team
  - Docs
  - Tasks
- On click:
  → open right-side panel
  → show relationships + explanation

-----------------------------------

3. 👥 TEAM INTELLIGENCE
- Minimal user cards
- Show:
  - Name
  - Role
  - Expertise tags
- Subtle hover interaction

-----------------------------------

4. 📚 SMART DOCUMENTS
- AI-recommended docs
- Show:
  - Title
  - Why it's relevant

-----------------------------------

🧠 TRUST LAYER (VERY IMPORTANT):

Add explanation block:

"Why this suggestion?"

- Based on:
  ✓ Team structure  
  ✓ Documents  
  ✓ Activity patterns  

Add:
- Confidence score (e.g. 87%)
- Small tooltip: "AI-generated insight"

-----------------------------------

🎯 PERSONALIZATION:

Top dropdown:
"Select your role"

Options:
- Frontend Developer
- Backend Developer
- Product Manager

UI should dynamically update content based on selection.

-----------------------------------

📊 IMPACT SECTION:

Minimal stats:

- "70% faster onboarding"
- "3x faster clarity"
- "Less confusion, more execution"

Use simple typography (no flashy charts)

-----------------------------------

🎨 DESIGN SYSTEM:

- Dark mode default
- Neutral color palette (gray, soft blue, subtle gradient)
- Typography: clean, readable
- Generous spacing
- Smooth transitions (200–300ms)

-----------------------------------

✨ MICRO-INTERACTIONS:

- Hover: soft elevation
- Click: subtle scale
- Loading: skeleton UI (not spinners everywhere)

-----------------------------------

🚫 AVOID:

- No chatbot UI
- No bright gradients
- No heavy animations
- No clutter
- No fake complexity

-----------------------------------

🏆 FINAL PRODUCT FEEL:

The UI should communicate:

"This is intelligent"
"This saves time"
"This is real"

NOT:
"This is a hackathon prototype"

-----------------------------------

💡 ONE-LINER:

"Context turns company chaos into clear, personalized action."

-----------------------------------

🎯 OUTPUT REQUIREMENT:

- Fully responsive UI
- Clean component structure
- Production-level design quality
- Smooth user experience
