You are a senior product engineer and UI designer. Build "Onboard" — an AI-powered employee onboarding SaaS that converts scattered company knowledge into personalized, role-specific briefs for new hires. Deliver a single production-quality App.jsx using React + Tailwind CSS + Framer Motion + Lucide React.

─── OUTPUT STRUCTURE ───────────────────────────────────────
One file. Two views toggled with useState: Landing and Dashboard.
All mock data in a single MOCK_DATA const at the top.
Custom hooks: useTypewriter(text, speed), useDarkMode(), useOnScreen(ref).
Reusable atoms: Button, Badge, Avatar, Card.
Mobile-first. Sidebar collapses to bottom nav under 768px.
Dark/light mode toggle using Tailwind dark: classes.
No truncation. No placeholder comments. No dead code.

─── DESIGN RULES ───────────────────────────────────────────
Font: Inter or system-ui. Accent: indigo. Base: slate/zinc.
Border radius: rounded-2xl for cards, rounded-lg for inputs.
Shadows: shadow-sm or shadow-md only. No glow.
Motion: Framer Motion — fadeInUp, staggerChildren, whileInView.
Icons: Lucide only — 16px UI, 20px feature cards.
No blob art. No gradients. No rainbow schemes.
No Bootstrap, Material UI, or Chakra. Pure Tailwind only.
All copy must be product-realistic. No Lorem ipsum.
