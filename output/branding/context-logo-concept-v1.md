# Context logo concept

Generated with the built-in image generation tool. The transparent PNG is a design concept, not a vector master.

The connected C represents service dependencies and correlated evidence. The cyan node emphasizes the root cause. Indigo follows the application's existing palette; the navy wordmark is intended for light backgrounds.

## Generation prompt

Use case: logo-brand.
Asset type: primary logo concept for Context, an existing real-time incident intelligence web application used by engineers, SREs, and managers.
Primary request: Create one original, polished logo lockup that captures Context's actual purpose: connect service dependencies and deployment events, follow cascading failures back to their root cause, turn noisy telemetry into a clear explanation, and help people respond with confidence.
Scene/backdrop: genuinely transparent background, no background rectangle, no checkerboard drawn into the image.
Subject: a distinctive geometric capital C symbol built from a single confident connected path with just three or four rounded service-node junctions, one clearly emphasized cyan root-cause node nestled toward the opening of the C. Communicate connected evidence resolving into one focal point. Keep the construction bold, simple, balanced and memorable, readable as C even at favicon size. Avoid a complex literal network diagram.
Composition: single horizontal logo, symbol at left and the exact word "Context" at right, centered with generous transparent margin; icon about the height of the wordmark or slightly larger. One logo only.
Style/medium: precise flat vector-like brand design rendered as a high-resolution PNG, crisp edges, uniform intentional geometry, premium developer infrastructure software, calm and intelligent, approachable without being playful.
Palette: solid indigo #6366F1 for the main symbol, one cyan #22D3EE node accent, deep navy #0F172A wordmark. No gradients, glows, shadows, 3D effects or texture.
Typography: "Context" spelled C-o-n-t-e-x-t, exact capitalization, custom-looking contemporary geometric sans serif, medium to semibold weight, subtly rounded corners and excellent optical kerning, legible and restrained.
Constraints: original design, scalable silhouette, balanced negative space, no slogan, no extra labels, no mockup objects, no watermark. Do not use a generic sparkle, brain, shield, infinity knot, existing technology-company emblem, or detailed cartoon robot. The AI assistant inside the product has its own robot icon; this main logo must represent the whole connected incident intelligence product.
